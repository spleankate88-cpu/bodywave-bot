# SDO · Танцевально-двигательная терапия

Источник: `https://sdo.appkk.ru/mod/resource/view.php?id=213964`

Материал курса:

- `role_body_component_tdt.pdf` — исходный PDF из SDO.
- `role_body_component_tdt.txt` — извлеченный текст PDF для работы над ботом.

Ключевые темы для BodyWave:

- танцевально-двигательная терапия как отдельное направление психотерапии;
- полимодальный подход: связь ТДТ с телесной терапией, expressive arts и арт-терапией;
- взаимосвязь тела и психики;
- четыре области телесного компонента: мышечное напряжение/расслабление, кинестетика, образ тела, выразительное движение;
- мышечные паттерны как доступ к эмоциональному опыту;
- кинестетическая эмпатия и невербальная коммуникация;
- движение как способ развивать образ тела и менять отношение к себе;
- выразительное движение как мост между действием, эмоцией и осознаванием.

В бота добавлена практика `body_component_awareness`, которая превращает эти темы в мягкую пользовательскую последовательность.
