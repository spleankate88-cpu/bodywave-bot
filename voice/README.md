# BodyWave voice recordings

Put recorded practice audio here when you want the bot to use a human voice.

Naming:

```text
voice/ru/<practice_id>/step_1.mp3
voice/ru/<practice_id>/step_2.mp3
voice/ru/<practice_id>/step_3.mp3
voice/ru/<practice_id>/step_4.mp3
```

Supported formats: `.mp3`, `.m4a`, `.ogg`, `.wav`.

Example:

```text
voice/ru/grounding/step_1.mp3
```

If a file is missing, the bot uses automatic generated audio for that step.
