# BodyWave Therapy Bot 🌊

Соматический Telegram-бот для движения, эмоций и контакта с телом.

BodyWave помогает подобрать мягкую телесную практику по текущему состоянию: тревоге, усталости, напряжению, злости или потере контакта с собой.

Бот использует:

- танцевально-двигательный подход
- соматические образы
- практики опоры
- движение через дыхание
- идею внутренних потоков тела

Здесь не нужно двигаться красиво. Важно только заметить, что тело уже говорит.

## Что умеет бот

- подбирает практику по эмоции, месту ощущения в теле и времени
- ведет короткие практики текстом или голосом
- предлагает мягкий финал после практики
- помогает заметить изменения без оценки
- дает короткий AI-отклик на свободное описание состояния

## Библиотека практик

В боте есть библиотека BodyWave Content Library V1:

- Bartenieff Fundamentals
- паттерны развития
- авторский блок “Внутренние потоки”

Каждая практика хранит название, категорию, длительность, теги, инструкцию и вопрос для рефлексии.

## Дисклеймер

BodyWave не заменяет психотерапию, медицинскую помощь или работу с врачом.

Это мягкий соматический инструмент для самонаблюдения, движения и контакта с телом.

Если тебе очень плохо, есть панические состояния, травма или сильные симптомы, лучше обратиться к специалисту.

## Команды

- `/start` — начать заново
- `/menu` — открыть главное меню
- `/practices` — посмотреть доступные практики
- `/music` — музыка для практики
- `/voice_test` — проверить голосовой режим
- `/about` — о BodyWave
- `/ai_status` — проверить подключение AI
- `/help` — помощь

## Запуск

Для Railway нужны переменные окружения:

```text
TELEGRAM_TOKEN=токен Telegram-бота
ANTHROPIC_API_KEY=ключ Anthropic для AI-ответов
```

`TELEGRAM_TOKEN` обязателен. `ANTHROPIC_API_KEY` нужен только для AI-отклика на свободный текст.

## Голосовые практики

Если в папке есть готовая запись полной практики, бот отправит ее вместо синтетического голоса:

```text
voice/ru/<practice_id>/full.mp3
```

Если записи нет, бот соберет голосовую инструкцию из текста и добавит план времени для каждого шага.
