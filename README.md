# 🌊 BodyWave — Telegram Bot

Бот по танцевально-двигательной терапии.

---

## 🚀 Запуск на Railway (бесплатно)

### Шаг 1 — GitHub
1. Зайди на github.com → создай аккаунт если нет
2. Нажми **New repository** → название `bodywave-bot`
3. Загрузи файлы проекта: `bot.py`, `requirements.txt`, `railway.toml`, `.env.example`

### Шаг 2 — Railway
1. Зайди на railway.app
2. **New Project** → **Deploy from GitHub repo**
3. Выбери репозиторий `bodywave-bot`
4. Railway сам определит Python и установит зависимости

### Шаг 3 — Переменные окружения
В Railway → твой проект → **Variables** → добавь:

```
TELEGRAM_TOKEN = твой_токен_от_BotFather
ANTHROPIC_API_KEY = твой_ключ_от_Anthropic
```

`TELEGRAM_TOKEN` обязателен. `ANTHROPIC_API_KEY` можно не добавлять на первом запуске:
бот всё равно будет работать, просто вместо AI‑отклика покажет короткую заготовленную фразу.

### Шаг 4 — Запуск
Railway автоматически запустит бота после добавления переменных.
Проверь в разделе **Deployments** — должно быть ✅ Active.

## ➕ Как добавить новую практику

Открой `bot.py`, найди раздел `PRACTICES` и добавь новую практику в список `mini` или `full`:

```python
{
    "id": "my_practice",           # уникальный ID
    "title": "🌿 Название",
    "subtitle": "Автор · время",
    "tags": ["тревога", "стресс"],  # ключевые слова для подбора
    "steps": [
        ("Название шага 🌊", "Текст инструкции..."),
        ("Второй шаг 💧", "Текст..."),
    ]
},
```

Сохрани файл → Railway автоматически перезапустит бота.

## 🔑 Где взять Anthropic API Key

1. Зайди на console.anthropic.com
2. Создай аккаунт
3. **API Keys** → **Create Key**
4. Скопируй ключ (начинается с `sk-ant-...`)

## 📱 Команды бота

- `/start` — начать сначала
- `/menu` — открыть главное меню
- `/practices` — посмотреть доступные практики
- `/materials` — посмотреть материалы курса
- `/music` — открыть Spotify-плейлист для практики
- `/help` — помощь и правила безопасности

## 🧭 Что уже есть в MVP

- выбор русского или английского языка
- три сценария входа: текущее состояние, эмоция, конкретный запрос
- подбор короткой или длинной практики по тегам и времени
- пошаговое прохождение практики с прогрессом
- практики по мотивам курса «Внутренний океан»: палсинг, жидкие ноги и таз, руки как волны от стоп, вода в верхней части тела
- практики по материалам 2–6 занятий: кровь, венозное/артериальное/капиллярное течение, ликвор, лимфа, суставное скольжение, интеграция жидкостей
- практика по материалу SDO 13.1: телесный компонент эмоции, мышечный след, образ тела и выразительный жест
- команда `/materials` со ссылками на папки занятий в Google Drive
- команда `/music` со ссылкой на Spotify-плейлист для практик
- мягкое предупреждение, что бот не заменяет терапию или экстренную помощь
- кризисный ответ, если пользователь пишет про риск самоповреждения
- опциональный AI‑отклик через Anthropic для свободного текстового описания состояния

## 🌊 Материалы курса

В программу добавлены практики по материалам:

- Google Drive: `Внутренний Океан`
- чаты занятий 1–6: `materials/inner_ocean/chats/`
- `Презентация 3.pdf`
- `Презентация 4.pdf`
- `Презентация 5.pdf`
- SDO: `13.1 Роль телесного компонента в танцевально-двигательной терапии`
- PDF и извлеченный текст SDO: `materials/tdt/sdo/`

PDF‑файлы сохранены как источник курса, но автоматическое извлечение текста из них ограничено:
они выглядят как Keynote/PDF со слайдами и изображениями. Практики сейчас собраны из чатов
занятий, видимых тем курса и доступных PDF.

Материал SDO 13.1 извлечен в текст и использован как основа для практики
`body_component_awareness`.
